# Habit Tracker

A simple and calm habit tracker built with React.  
This app helps users track weekly habits, manage breaks, and stay consistent without overwhelming UI.

---

## Features

- Add new habits
- Set weekly targets
- Track daily progress
- Weekly completion system
- Break mode for habits
- Archive habits
- Edit weekly target with limited edits
- Responsive layout
- Local storage persistence
